# AI Agent Skill for One Person Company

AI Agent Skill Navigator for one-person companies.

This project is designed as an SEO-first, affiliate-first decision platform for solo operators choosing AI agent skills, workflows, tools, and templates.

## Structure

```txt
apps/web          Next.js website, SEO routes, content rendering
apps/agent-engine Future Python agent engine and automation layer
command-center    File-driven planning, tasks, progress, and results
data              Local seed content and future generated data
scripts           Utility scripts
```

## Development

```bash
npm install
npm run dev
npm run typecheck
npm run build
```

## Current Scope

The first foundation focuses on:

- command-center discipline
- MVP content schemas
- first 10 skill records
- first 5 commercial comparison outlines
- basic SEO-ready web scaffold
